numbinder modules guide
=======================

A module is a single Python file (.py) in C:\numbinder\modules\.

numbinder loads it at startup and adds it to the button "Type" list, marked with 🧩.

WARNING
-------
Modules run with your account's rights. They can read and change files, start
programs, read the clipboard and send keys. Install only code you trust.


1. INSTALLING A MODULE
----------------------
From the app: Settings -> Modules -> "Install module...".
The first time, a warning window appears. You must accept it before installing.

By hand: copy the .py file into C:\numbinder\modules\ and restart numbinder.

Then select the module in the button's "Type" field (it starts with 🧩).


2. WRITING A MODULE
-------------------
Copy modules\_template.py, rename it (for example, my_module.py), edit it and
place it in modules\.

Required structure:

    MODULE = {
        "id": "my_module",                                  # unique, no spaces
        "name": {"ru": "My module", "en": "My module"},    # shown in the list
        "description": {"ru": "What the module does.", "en": "What the module does."},          # optional
        "version": "1.0.0",                                 # optional
        "author": "you",                                    # optional
    }

    def run(ctx, cfg):
        ...

If the file has no MODULE with an "id", or no run() function, the module is
skipped and the error is written to the log.


3. HELPERS (ctx)
----------------
    ctx.osd("text")         show a message on screen
    ctx.log("text")         write a line to this run's log
    ctx.settings()          the module's own settings dictionary (saved in config.json)
    ctx.save_settings()     save config.json after changing ctx.settings()

cfg holds the button's own settings: cfg.get("Type"), cfg.get("Path"),
cfg.get("ProcessName"), and so on.

An exception inside run() does not crash the app. It is written to the log
and shown with ctx.osd().


4. LIBRARIES
------------
A module may import any pip package. These are already installed with numbinder:
pyperclip, psutil, pycaw, pystray, Pillow, comtypes.
For others, run: python -m pip install package_name


5. EXAMPLE
----------
modules\layout_fixer.py is the built-in layout fixer. Use it as a reference.


6. TIPS
-------
- Restart numbinder after changing a module file.
- Files whose names start with "_" are not loaded. That is why _template.py can stay.
- Keep run() short. For long work, start a thread inside it.
