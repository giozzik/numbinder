numbinder modules / Модули numbinder
====================================

A module is one Python file (.py) in C:\numbinder\modules\.
Модуль — один Python-файл (.py) в папке C:\numbinder\modules\.

numbinder loads it at startup and adds it to the button "Type" list with a 🧩 icon.
numbinder загружает его при запуске и добавляет в список "Тип" кнопок с иконкой 🧩.

WARNING / ВНИМАНИЕ
Modules run with your account's rights: they can read and change files, start programs,
read the clipboard and send keys. Install only code you trust.
Модули работают с правами вашей учётной записи: могут читать и менять файлы, запускать
программы, читать буфер обмена и отправлять нажатия. Ставьте только код, которому доверяете.


1. INSTALLING / УСТАНОВКА
-------------------------
From the app: Settings -> Modules -> "Install module..." (the first time a warning appears).
Из приложения: Настройки -> Модули -> "Установить модуль..." (при первой установке — предупреждение).

By hand: copy the .py file to C:\numbinder\modules\ and restart numbinder.
Вручную: скопируйте .py в C:\numbinder\modules\ и перезапустите numbinder.

Then pick the module in the button's "Type" field (it starts with 🧩).
Затем выберите модуль в поле "Тип" кнопки (он начинается с 🧩).


2. WRITING A MODULE / НАПИСАНИЕ МОДУЛЯ
---------------------------------------
Copy modules\_template.py, rename it (e.g. my_module.py), edit it, and put it in modules\.
Скопируйте modules\_template.py, переименуйте (например my_module.py), измените и положите в modules\.

Required structure / Обязательная структура:

    MODULE = {
        "id": "my_module",                                  # unique, no spaces / уникальный, без пробелов
        "name": {"ru": "Мой модуль", "en": "My module"},    # shown in the list / название в списке
        "description": {"ru": "...", "en": "..."},          # optional / необязательно
        "version": "1.0.0",                                 # optional / необязательно
        "author": "you",                                    # optional / необязательно
    }

    def run(ctx, cfg):
        ...

If MODULE with an id, or run(), is missing, the module is skipped and the error goes to the log.
Если нет MODULE с id или функции run(), модуль пропускается, а ошибка идёт в лог.


3. HELPERS / ПОМОЩНИКИ (ctx)
----------------------------
    ctx.osd("text")          show a message on screen / показать сообщение на экране
    ctx.log("text")          write to this run's log / записать в лог текущего запуска
    ctx.settings()           the module's own settings dict, saved in config.json
                             собственный словарь настроек модуля, хранится в config.json
    ctx.save_settings()      save config.json after changing ctx.settings()
                             сохранить config.json после изменения ctx.settings()

cfg is the button's own settings: cfg.get("Type"), cfg.get("Path"), cfg.get("ProcessName"), etc.
cfg — настройки самой кнопки: cfg.get("Type"), cfg.get("Path"), cfg.get("ProcessName") и т. д.

An exception inside run() does not crash the app: it is logged and shown with ctx.osd().
Исключение внутри run() не роняет программу: оно записывается в лог и показывается через ctx.osd().


4. LIBRARIES / БИБЛИОТЕКИ
-------------------------
A module may import any pip package. Already installed with numbinder:
pyperclip, psutil, pycaw, pystray, Pillow, comtypes.
Модуль может импортировать любые пакеты pip. Уже установлены вместе с numbinder:
pyperclip, psutil, pycaw, pystray, Pillow, comtypes.
For others run: python -m pip install package_name
Для остальных: python -m pip install имя_пакета


5. EXAMPLE / ПРИМЕР
-------------------
modules\layout_fixer.py is the built-in layout fixer. Read it as a reference.
modules\layout_fixer.py — встроенный модуль исправления раскладки. Используйте как образец.


6. TIPS / СОВЕТЫ
----------------
- Restart numbinder after changing a module file.
  После изменения файла модуля перезапустите numbinder.
- Files starting with "_" are not loaded (that is why _template.py is safe to keep).
  Файлы с "_" в начале не загружаются (поэтому _template.py можно оставить).
- Keep run() short; for long work start a thread inside it.
  run() должен быть коротким; для долгой работы запускайте поток внутри.
